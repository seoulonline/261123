모션 그래픽

좋은 아이디어는 이미 누군가 만들어 두었습니다. Prompt Motion에는 Claude로 만든 영상과 그 프롬프트가 함께 실려 있습니다. 구조만 빌려 우리 단원으로 바꾸면 됩니다.

자세히접기

고르는 법

  • Prompt·Skill 필터, Kinetic type·Diagrams·Charts 태그로 좁힙니다
  • 작품 페이지에서 모델과 사용 기술(Stack)을 확인합니다

진행

  1. 수업에 쓸 작품을 고릅니다
  2. 구조만 참고해 우리 단원 버전으로 요청합니다
  3. "속도를 늦춰 줘"처럼 한 번에 하나씩 고칩니다

주의

  • 렌더링은 오래 걸립니다. 완성본은 미리 만들어 둡니다
  • 작품과 프롬프트의 저작권은 원작자에게 있습니다. 링크로만 안내합니다
프롬프트
중학교 3학년 '에너지 전환과 보존' 단원 도입용 웹페이지를 HTML 한 파일로 만들어 줘.
- 첫 화면에는 질문 하나: "롤러코스터는 왜 첫 언덕이 가장 높을까?"
- 스크롤하면 수레가 내려가고, 위치 에너지와 운동 에너지 막대그래프가 함께 바뀌게
- 마찰이 없을 때와 있을 때를 버튼으로 비교(마찰이 있으면 일부가 열에너지로 바뀌는 것까지)
- 휴대폰에서도 깨지지 않게, '동작 줄이기' 설정을 켠 사용자에게는 애니메이션 멈추기
- 코드에는 학생과 교사가 이해할 수 있는 한국어 주석 달기

개념 영상

개념 영상의 관건은 무엇일까요? 일상의 질문에서 출발해 정의로 끝나는 흐름입니다. Customize 화면에 주제와 대상만 넣으면 그 흐름을 갖춘 프롬프트가 나옵니다.

자세히접기

참고 작품

  • Derivative concept explainer: Manim(수학·과학 애니메이션)과 edge-tts(Microsoft Edge 음성 합성)로 만든 영상

진행

  1. Customize에 주제 '자유 낙하', 대상 '중학교 3학년', 언어 Korean, 목소리 ko-KR-SunHiNeural을 넣습니다
  2. 대본과 장면 구성표부터 확인합니다
  3. 확인한 뒤 렌더링합니다

주의

  • 과학적 정확성은 교사가 확인합니다. '공기 저항을 무시하면' 같은 조건이 빠지기 쉽습니다
  • 자막은 꼭 넣습니다
프롬프트
Manim으로 중학교 3학년 대상 1분짜리 '자유 낙하' 개념 영상을 만들어 줘.
- 시작 질문: "무거운 공과 가벼운 공을 같은 높이에서 동시에 떨어뜨리면 무엇이 먼저 떨어질까?"
- 순서: 질문 → 직관 → 쉬운 예 → 어려운 예 → 정리 → 생각해 볼 질문
- 정리 문장: 공기 저항을 무시하면 질량과 관계없이 같은 가속도(약 9.8 m/s²)로 떨어진다
- 내레이션은 한국어, edge-tts 목소리 ko-KR-SunHiNeural, 자막은 문장마다 맞추기
- 먼저 대본과 장면 구성표를 보여 주고, 내가 확인하면 1920×1080 MP4로 만들어 줘
참고 작품Customize

책 PDF

책을 학습시키는 것이 아닙니다. 저장해 두고 그때그때 참조하는 것입니다. 그래서 답을 받을 때 근거 쪽수를 함께 묻습니다.

자세히접기
아티팩트에 저장프로젝트 지식
범위어느 대화에서든그 프로젝트 안에서만
불러오기어떤 아티팩트인지 짚어 줍니다자동으로 참고합니다
  • 본인이 가진 책을 개인 참고용으로만 씁니다
  • 원문은 나만 보기. 공유는 내가 정리한 수업안만
프롬프트
『책 제목』 아티팩트를 읽고, 중학교 3학년 '운동과 에너지' 단원에 적용할 수업 아이디어 3개를 제안해 줘.
- 아이디어마다: 활동 이름, 학생 활동 순서(3단계), 준비물
- 근거가 된 책의 장과 쪽수를 함께 적어 줘
- 책에 없는 내용은 '제안'이라고 따로 표시해 줘

GitHub 배포

학생은 로그인 없이 링크 하나로 들어와야 합니다. 그래서 학생용 앱은 GitHub Pages로 배포합니다.

자세히접기

진행

  1. GitHub에 공개(Public) 저장소를 만듭니다
  2. Claude와 GitHub를 연결합니다
  3. 코드를 만들어 main 브랜치에 커밋하게 합니다
  4. Settings → Pages에서 Branch를 main, 폴더를 / (root)로 저장합니다
  5. https://아이디.github.io/저장소이름/ 으로 접속합니다

아티팩트와 무엇이 다른가

  • 아티팩트: 빨리 만들고 교사끼리 나눕니다
  • GitHub Pages: 누구나 링크로 들어옵니다. 한 학기 내내 쓰는 앱에 맞습니다

주의

  • 공개 저장소는 누구나 봅니다. 학생 정보, 비밀번호, API 키는 커밋하지 않습니다
프롬프트
이 저장소에 '자유 낙하 실험 기록' 웹앱을 index.html 한 파일로 만들어 main 브랜치에 커밋해 줘.
- 낙하 높이(m)를 입력하면 걸리는 시간을 계산(공기 저항 무시, g = 9.8 m/s²)
- 학생이 잰 시간과 계산값을 표로 비교하고 차이를 %로 보여 주기
- 데이터는 학생 브라우저에만 저장하고 서버로 보내지 않기
- 코드에는 학생과 교사가 이해할 수 있는 한국어 주석 달기

캘린더

공문을 붙여 넣으면 일정이 캘린더에 들어가고, 휴대폰에서도 바로 보입니다. 등록 전 확인 한 번이 실수를 막습니다.

자세히접기
  • 커넥터에서 Google Calendar를 연결합니다
  • 휴대폰은 같은 Google 계정으로 Google 캘린더 앱에 로그인하거나, 아이폰 기본 캘린더에 계정을 추가하면 동기화됩니다
  • 시간이 부족하면 시연만 합니다
프롬프트
아래 공문에서 일정만 뽑아 내 구글 캘린더에 등록해 줘.
- 등록 전에 날짜, 시간, 장소, 준비물을 표로 먼저 보여 줘
- 시간이 적혀 있지 않은 일정은 종일 일정으로
- 제목 앞에 [공문]을 붙여 줘

Part 3 · 자동화하기

잘 된 작업은 반복할 수 있어야 합니다

스킬

한 번 잘 된 작업을 매번 처음부터 다시 할 필요는 없습니다. 순서를 스킬로 저장해 두면 다음에는 한 줄이면 됩니다.

자세히접기

만드는 법

  • 잘 된 대화 끝에 "방금 과정을 스킬로 만들어 줘" → 검토 카드에서 확인 → 저장

강사 시연

  • 공문 파일 PDF 일괄 변환과 월별 분류
  • 장바구니 캡처로 물품 구입 품의 3종 만들기
  • 공문 속 일정 캘린더 등록

주의

  • 스킬 안에 개인정보나 비밀번호를 적지 않습니다
  • 스킬 하나에는 일 하나만 담습니다
프롬프트
방금 한 '공문 → 캘린더 등록' 과정을 스킬로 만들어 줘.
- 언제 쓰는지: 공문, 메신저, 메일 내용을 주며 일정 등록을 요청할 때
- 순서: 일정 뽑기 → 표로 확인받기 → 등록 → 겹치는 일정 알려 주기
- 제목 규칙: 앞에 [공문]

예정

정해 둔 시간이 되면 Claude가 알아서 일을 시작합니다. 스킬과 예정이 만날 때 비로소 자동화가 됩니다.

자세히접기
  • 실행할 때마다 새 대화에서 시작합니다. 필요한 정보는 프롬프트에 모두 담습니다
  • 승인 설정을 확인합니다. 승인이 필요한 단계에서 멈출 수 있습니다
  • 내 컴퓨터 파일이 필요하면 그 시간에 컴퓨터가 켜져 있어야 합니다

교사용 예

  • 매일 아침 일정 브리핑
  • 금요일마다 다음 주 할 일 정리
  • 수행평가 마감 전날 안내문 초안
프롬프트
평일 아침 7시 30분마다 아래 일을 해 줘.
1) 내 구글 캘린더에서 오늘 일정을 시간순으로 정리
2) 일정마다 준비할 것을 한 줄씩
3) 오늘 마감인 일이 있으면 맨 위에 표시
결과는 5줄 안으로 짧게.
